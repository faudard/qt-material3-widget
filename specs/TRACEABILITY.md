# Vision-to-Release Traceability

Required chain for promoted work:

Vision ID -> Capability Epic -> Milestone -> Spec Kit Feature -> Requirement -> Task -> PR/Commit -> Test/Evidence -> Release Evidence.

## Rules

1. Vision IDs are stable.
2. Research code does not equal delivery.
3. Every active requirement has test/evidence ownership.
4. Tasks reference requirement IDs.
5. Release readiness can enumerate satisfied/unsatisfied requirements.
6. Superseded items remain historically resolvable.
