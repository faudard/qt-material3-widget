# Implementation Plan

## Phase 016.A — Deterministic Buttons visual contract

1. Define a closed schema distinct from semantic reference suites.
2. Generate all 50 logical cases from the required Button model axes.
3. Bind every case to a fixed state setup and evidence-backed renderer suite.
4. Pin the raster environment and four isolated target identities.
5. Generate the 200 canonical future reference paths.
6. Enforce zero-tolerance/no-bypass policy and reject premature images.
7. Integrate static validation into repository health and document the boundary.

## Phase 016.B — Deterministic capture runner

1. Add a test-only Button state controller with direct fixed-phase injection.
2. Render the exact canvas and widget rectangle from the contract.
3. Verify style, QPA, DPR and exact font selection before capture.
4. Normalize PNG data and emit the complete runtime fingerprint.
5. Capture all 50 cases on one declared target without accepting references yet.

Steps 1-4 are source-complete. Step 5 requires a declared Qt runner and remains
the next runtime increment; static checks cannot promote it.

## Phase 016.C — Reference inventory and comparator

1. Define closed reviewed-reference and comparison-report manifests.
2. Implement strict normalized-PNG decode and exact pixel/channel/SSIM scoring.
3. Reject incomplete inventories, malformed images, hashes, environments and
   cross-target substitution before artifact creation.
4. Emit deterministic actual/diff/metric diagnostics and a report in a fresh,
   non-reference directory.
5. Capture, review and commit one complete 50-image target set atomically.
6. Transition only that reference set to `reviewed` and activate its CI job.

Steps 1-4 are source-complete and exercised with synthetic images. Steps 5-6
remain runtime work and cannot be promoted from static evidence.

## Phase 016.D — Multi-target visual matrix

1. Capture and review the remaining three complete target sets.
2. Run each target only against its own fingerprinted references.
3. Report Qt 5/Qt 6 and platform differences without reference substitution.
4. Make the complete matrix a required CI conformance gate.

The next increment is T017 runtime capture on one declared Qt environment,
followed by review and 016.C2 activation of that exact 50-case target set.
