# ThemeModel Data Model
- ThemeOptions: authored generation inputs.
- ColorScheme: semantic color roles.
- TypographyScale, ShapeScale, ElevationScale.
- Motion/state/density/icon/accessibility values.
- Theme: resolved aggregate model.
- ThemeBuilder: deterministic transformation.
- Model diagnostics/validation.
Excluded: JSON/XML/string persistence, ThemeContext/ThemeManager/observers.
