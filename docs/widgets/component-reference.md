# Component reference

This catalog is the consumer-facing inventory of every release-scoped public widget. It is intentionally derived from the canonical component registry: public type, installed header, Gallery route, focused test and maturity must stay aligned with release metadata.

For behavioral details, follow the family guide in the **Guide** column. Every family guide follows the [consumer component documentation standard](component-documentation-standard.md): when to use, states, keyboard, accessibility, RTL and examples.

## Consumer guarantees

Release-scoped entries in this catalog must have an installed public header, public widget type, Gallery route, documentation path and focused test target in the registry. CI validates those invariants and verifies that the referenced documentation contains the component's public type and the family-level interaction contract.
