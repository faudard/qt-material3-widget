# Migrating from 1.0 to 1.1

This page is the migration ledger for the 1.1 release line.

## Compatibility expectation

The documented installed public headers are covered by the 1.x source-compatibility policy. Binary compatibility is best-effort unless a stricter ABI guarantee is explicitly published.

## Before upgrading

- pin the exact 1.1 tag or commit;
- read the 1.1 section of `CHANGELOG.md`;
- rebuild from a clean CMake build directory;
- run your application under both light and dark themes;
- retest keyboard navigation, accessibility metadata and RTL if your application depends on them.

## Source changes

No migration-specific source change is documented here until a 1.1 change actually requires consumer action. Do not add speculative renames or compatibility advice.

When a 1.1 change requires action, record it here with:

- the 1.0 API or behavior;
- the 1.1 API or behavior;
- a minimal before/after example;
- whether the change is required or optional;
- any Qt 5/Qt 6 difference.

## Theme persistence

Theme JSON has its own `formatVersion`. A library version update does not by itself imply a persistence-format change. Follow the schema/version notes when such a change is introduced.
