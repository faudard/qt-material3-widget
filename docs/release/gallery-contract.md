# Gallery contract

The gallery is not only a demo. It is the visual QA contract for the library.

Each mature component page should expose:

- default state
- hovered state
- focused state
- pressed state
- disabled state
- error state where relevant
- loading/busy state where relevant
- light and dark theme
- density variants
- high contrast variant
- automation ids
- accessible name/description summary
- resolved spec/token inspection

Recommended routes:

```text
/gallery/buttons
/gallery/inputs
/gallery/selection
/gallery/surfaces
/gallery/navigation
/gallery/progress
/gallery/data
/gallery/states
/gallery/accessibility
/gallery/high-dpi
```
